## Tecnologias

- **Next.js 16** (App Router) e **React 19**
- **TypeScript**
- **Tailwind CSS 4**
- Letra **Geist**, carregada pelo `next/font`
- Tema claro e escuro automático, de acordo com o aparelho de quem visita
- Hospedagem na **Vercel**

## Estrutura

| Arquivo | O que tem |
|---|---|
| `app/dados.ts` | **Todos os textos**: perfil, projetos, experiência, certificados e competências. Para atualizar o portfólio, é só mexer aqui. |
| `app/page.tsx` | A página, que monta as seções a partir do `dados.ts` |
| `app/layout.tsx` | Idioma, letras e o título e a descrição para o Google |
| `app/globals.css` | Cores do tema claro e escuro |
| `public/` | Imagens (a foto entra aqui) |

## Rodar no computador

Com o [Node.js](https://nodejs.org) instalado, dentro da pasta:

```bash
npm install     # baixa as bibliotecas do projeto (só na primeira vez)
npm run dev     # abre o site em http://localhost:3000 e atualiza sozinho a cada mudança
npm run build   # monta a versão final e mostra se tem algum erro antes de publicar
```
